Tobago comes with several predefined themes, but implementing a custom theme is also possible.

  • Standard Theme - The default theme by Bootstrap to have a clean base to abstract from.
  • Scarborough - Minimalistic standard theme with basic changes from the Standard Theme.
  • Speyside - A nature-inspired theme with warm and earthy tones.
  • Roxborough - A dark theme with high color contrast and bright accents.
  • Charlotteville - A theme that comes with blue color tones which resemble the sky.

Choosing of themes can be application wide, user or group specific. Images and other resources can be theme dependant as well as the application pages can be designed separately for each supported theme.

To use a predefined theme like "speyside", it has to be configured in the tobago-config.xml.

<tobago-config> <theme-config> <default-theme>speyside</default-theme> </theme-config> </tobago-config>

Besides the predefined themes, Tobago allows you to create your own theme for your project. This page explains the steps that are needed to define, build and use a custom theme.

A custom theme is based on the Tobago standard theme. The standard theme provides the JavaScript and the icons which are needed by Tobago. So the tobago-theme-standard must be a dependency of your project.

<dependency> <groupId>org.apache.myfaces.tobago</groupId> <artifactId>tobago-theme-standard</artifactId> <version>[Tobago-Version]</version> </dependency>

The custom theme must be defined in a tobago-config.xml (e.g. in WEB-INF/ or in META-INF/ of a JAR). The theme needs its own name and uses the standard theme as fallback. The CSS of the standard theme is replaced by your own CSS file. Use the default-theme element of the theme-config to activate the theme.

<tobago-config xmlns="http://myfaces.apache.org/tobago/tobago-config" xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance" xsi:schemaLocation="http://myfaces.apache.org/tobago/tobago-config http://myfaces.apache.org/tobago/tobago-config-5.1.xsd" version="5.1"> <name>my-project</name> <ordering> <after> <name>tobago-theme-standard</name> </after> </ordering> <theme-config> <default-theme>customTheme</default-theme> </theme-config> <theme-definitions> <theme-definition> <name>customTheme</name> <display-name>My Theme</display-name> <fallback>standard</fallback> <version>1.0.0</version> <resources production="true"> <includes> <style name="/tobago/customTheme/1.0.0/css/tobago.min.css"/> </includes> <excludes> <style name="/tobago/standard/[Tobago-Version]/css/tobago.min.css"/> </excludes> </resources> <resources production="false"> <includes> <style name="/tobago/customTheme/1.0.0/css/tobago.css"/> </includes> <excludes> <style name="/tobago/standard/[Tobago-Version]/css/tobago.css"/> </excludes> </resources> </theme-definition> </theme-definitions> </tobago-config>

The CSS of the theme can be built from SCSS with NPM/Node. For this, the _tobago.scss file is needed, which contains all the Tobago specific styles. You can get it by adding the GitHub repository of MyFaces Tobago as a dependency to your package.json. Use the tag that matches your Tobago version.

Tobago is based on Bootstrap, so Bootstrap is also needed as a dependency. The Bootstrap version must always be the same as the Bootstrap version used by Tobago. You can find the version in the tobago-theme/package.json of the corresponding Tobago release.

{ "name": "my-custom-theme", "scripts": { ... }, "dependencies": { "bootstrap": "5.3.8", "myfaces-tobago": "apache/myfaces-tobago#tobago-[Tobago-Version]" }, "devDependencies": { ... } }

The main SCSS file defines your own variables first, then imports Bootstrap and _tobago.scss. Your own styles and overwrites are added at the end.

// src/main/scss/my-custom-theme.scss // own variables, e.g. colors (overwrites Bootstrap defaults) $primary: #3a2564; @import "node_modules/bootstrap/scss/bootstrap"; @import "node_modules/myfaces-tobago/tobago-theme/src/main/scss/_tobago"; // overwrite styles tobago-progress { &.progress { border-style: dotted; } }

If some texts of the tobagoResourceBundle should be different in your theme, you can create a theme specific bundle named [themeName]Bundle. Tobago looks up the keys in this bundle first and uses the tobagoResourceBundle as fallback.

# src/main/resources/com/example/customThemeBundle.properties sheet.empty=There is nothing to show here. alert.close=Dismiss

Don't forget to register the bundle in the faces-config.xml. The var must be the name of the theme followed by Bundle.

<faces-config ...> <application> <resource-bundle> <base-name>com.example.customThemeBundle</base-name> <var>customThemeBundle</var> </resource-bundle> </application> </faces-config>
