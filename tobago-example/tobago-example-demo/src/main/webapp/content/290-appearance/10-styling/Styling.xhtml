Tobago offers several ways to adjust the look of individual components beyond what the theme provides.

The <tc:style> tag is used inside visual components (the component implements the interface).

  • With the attribute customClass a CSS class can be set. Since Tobago 6.12.0 the styleClass attribute can be used directly on a component instead of usind the style tag.
  • The attribute file includes a CSS file into the page.
  • Apart from the generic attributes binding and id all other attributes are CSS properties. These properties will be set in the parent component with respect to (CSP).

Because Tobago themes are based on , Bootstrap CSS classes like the are available.

The following example shows a tc:sheet in which some columns are visible or hidden depending on the size of the browser window.

<tc:badge value="small" styleClass="d-none d-sm-inline">          

For application icons, usually shown in browser tabs or bookmarks, use the <tc:metaLink> tag. It will be rendered as an HTML <link> tag inside the <head> tag.

There are different formats for different devices possible. Especially for mobile devices there are a lot of possibilities. In the you may find further information.

In this demo it is used in the template file main.xhtml. Example: <tc:metaLink href="\#{request.contextPath}/image/feather.svg" rel="shortcut icon"/> <tc:metaLink href="\#{request.contextPath}/image/feather.svg" rel="apple-touch-icon"/>
